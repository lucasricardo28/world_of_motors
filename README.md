Iniciando o projeto ? Use os comandos:

Iniciando virtualização para iniciar o projeto
*Iniciando env
# python3 -m venv env
* Activando o env criado 
# source env/bin/activate 

Instalando a dependência flask para poder rodar o flamework
# pip install flask

Por fim não esquece de subir o servidor:
# pythob3 app.py runserver

*lembrando: app.py é o arquivo principal
